# PasolSecurity planning system

This folder is the authoritative project record. The master plan owns scope; the current-milestone file owns the active slice; acceptance-checklist owns evidence-linked acceptance; progress-log owns chronological work; decisions, risks, tests, and deferred-work own their respective records.

Checkboxes mean `[ ]` not started, `[~]` in progress, `[x]` completed and verified with evidence, `[!]` blocked, and `[-]` explicitly deferred. Code existing alone never earns `[x]`.

To resume: read `STAGE-2-MASTER-PLAN.md`, `CURRENT-MILESTONE.md`, `ACCEPTANCE-CHECKLIST.md`, the latest `PROGRESS-LOG.md` entries, open `RISKS-AND-BLOCKERS.md`, and `TEST-EVIDENCE.md`; inspect repository state and recent commits; then select only the next unchecked task whose dependencies are complete.

Update this folder after every meaningful slice, before commits, and before completion claims. Never commit secrets, private keys, credentials, restricted dataset locations, or machine-specific sensitive details.
